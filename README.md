# Famdally Limited - Tanzanian Agricultural Trading

Official web platform for Famdally Limited, a Tanzanian-based coffee and agricultural trading company headquartered in Dar es Salaam.

## Overview
Famdally Limited specializes in sourcing, coordinating, and supplying green coffee (Arabica & Robusta) alongside diversified Tanzanian agricultural commodities (Avocados, Cashew Nuts, Sunflower Oil) to international markets.

## Structure
- `index.html`: Corporate portal & trade desk interface
- `assets/css/style.css`: Custom responsive styling
- `assets/js/main.js`: Interactive elements, navigation, enquiry form
- `assets/images/`: Visual assets, commodity photography, and company media

## Local Development
Open `index.html` in any modern web browser or serve with a local web server:
```bash
python -m http.server 8080
```
